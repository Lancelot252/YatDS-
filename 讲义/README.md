## 建议使用方式

- 课前：阅读“本周要解决的问题”和核心概念。
- 课中：跟随完整例子观察 Agent 的输入、动作和证据。
- 课后：用“速查清单”回顾，不必死记产品界面或命令。
- 实际使用 Agent 时：始终保留需求、工具输出、测试结果和 diff，避免只保存最终回答。
